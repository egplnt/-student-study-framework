# 高中生学习工程框架（student-study-framework）

面向 WorkBuddy 智能体的**高中生学习流程框架**。它把"安排学习"拆成四个可执行、可核查的部件：一套定位知识断点并设计桥接的方法、一套每日闭环流程、一套可逐条勾选的红线清单、一个资料入库前的可检索性体检脚本。

**本文件是面向使用者的说明书，不是效果承诺。** 文中每条机制都标注了依据来源与证据强度；没有第三方研究支持的部分明确标为"项目经验"。框架不保证提分，实际效果取决于资料储备、每日人力投入与执行纪律（见 [§7 效果边界](#7-效果边界)）。

## 1. 术语表

本框架使用下列术语，含义以此处定义为准。

| 术语 | 定义 |
| --- | --- |
| **学习工程** | 把学习过程当作可设计、可测量、可迭代的工程对象：明确输入（资料、时间、人力）、过程（搭桥、执行、校验）、输出（可核查的产出物），并保留每一步的判据。 |
| **扫盲点（scan gaps）** | 定位学生知识结构中的断点。具体输出为两类：①**知识跳跃点**——前置知识未掌握导致后续内容无法承接；②**概念卡点**——概念本身未建立理解，表现为同一知识点反复出错。 |
| **搭桥（bridge plans）** | 针对已定位的断点设计有先后次序的补救路径，每一步附带可判定的通过条件。 |
| **闸门测试（gating tests）** | 桥接完成后设置的检验点。通过才允许进入下一阶段；未通过则回到对应桥段重做。闸门测试的判据应当可数（数量、对错、能否口述），不接受"感觉会了"。 |
| **概念攻坚补充** | 概念卡点的隔离附件。卡点未突破前，不与常规测试混排，避免用其他题目的表现掩盖概念未通。 |
| **每日五步闭环** | ①生成打印清单 → ②手写执行 → ③90 秒三查勾选 → ④难篇送批 → ⑤对答案报结果。 |
| **红线清单** | 逐条可勾选的禁止项与前置项，分"进度/内容"与"工具/数据"两类。 |
| **可检索性体检** | 资料入库前实测其文本层是否真的可提取，判断标准为常用字命中率，而非"能否抽出字符"。 |

## 2. 框架包含什么

| 部件 | 作用 | 产物形态 | 主要依据 |
| --- | --- | --- | --- |
| 扫盲点 → 搭桥 | 定位断点、设计补救路径、设闸门测试 | 桥梁件（可打印 HTML） | 研究支持，见 [§4](#4-各条机制的依据) |
| 每日五步闭环 | 把"计划"落成"当天做完并可核对" | 每日打印清单 + 周任务单 | 研究支持（自我解释、脚手架撤除） |
| 参数化红线清单 | 固化禁止项与前置项，防止已知错误重复发生 | 勾选表 | 混合，见 [§4](#4-各条机制的依据) |
| 可检索性体检 | 防止把"文件在盘上"当成"内容可用" | 命令行脚本 + 判定表 | 项目经验，无第三方研究 |

框架对以下参数开放：学段、科目、目标分段、主线教辅、考试年份。更换学生时替换这些参数即可复用流程；但**红线条目与桥接逻辑来自具体案例，必须按学情重裁**（详见 [§3](#3-适用与不适用)）。

## 3. 适用与不适用

| 判定 | 条件 |
| --- | --- |
| **适用** | 高中理科（数学、物理、化学）；有一名能每日投入统筹的家长或执行人；已建立分学科可检索的本地资料库。 |
| **有条件适用** | 高中文科：框架流程仍可用，但桥接设计须自行调整——文科的知识断点更多是概念边界与论证结构，而非计算链。 |
| **有条件适用** | 初中、复读、小升初：五步闭环与红线清单可用；扫盲点→搭桥的判据（闸门测试）需按学段改写。 |
| **不适用** | 无人承担每日统筹：闭环第 ②③④⑤ 步断链，框架退化为一次性计划生成器。 |
| **不适用** | 无本地资料库且无 OCR 能力：桥接计划无素材支撑。 |
| **不适用** | 期望"装上就提分"：本框架不含数据资产与人力投入，见 [§7](#7-效果边界)。 |
| **不适用** | 大学阶段、成人自我学习：目标分段与考试结构差异过大，参数化外壳不成立。 |

## 4. 各条机制的依据

每条机制列出**依据来源**与**证据强度与限制**。强度分级：

- **强** = 多项元分析或大样本随机对照研究支持
- **中强** = 实证支持但样本或场景有限
- **中** = 存在争议或效应量依赖设计细节
- **经验级** = 本项目实践结论，无第三方研究

| 机制 | 依据 | 证据强度与限制 |
| --- | --- | --- |
| 先自己尝试，再看外部输入；不允许先看答案 | Kapur, M. (2016). *Examining Productive Failure, Productive Success, Unproductive Failure, and Unproductive Success in Learning*. Educational Psychologist, 51(2), 289–299. 自我解释效应：Chi, M. T. H., et al. (1989). *Self-explanations: How students study and use examples in learning to solve problems*. Cognitive Science, 13(2), 145–182. | 中。**不是"强"**：Productive Failure 的效应量高度依赖设计保真度与学科，边界条件见 [§5](#5-反向证据已知的失效条件)。自我解释研究原始样本量小。 |
| 归因权归学生：先自评，再与外部判读并排对照 | Sadler, R. S. (1989). *Reflections on expertise: A cognitive basis for instructional design*. Instructional Science, 18(2), 119–144. 反馈素养：Carless, D., & Boud, D. (2018). *Student feedback literacy in higher education: a critical review*. Teaching in Higher Education, 23(8), 1315–1340. | 中强。前者为理论论文非效果实验；后者为文献综述。学生须先具备基本评价词汇，否则需先补一段。 |
| 教师/AI 逐步退场（脚手架 fading） | Collins, A., Brown, J. S., & Newman, S. J. (1989). *Cognitive apprenticeship: Teaching crafts the learning of authentic activity*. In Lave, J., & Wenger, E. (Eds.), Knowing, Learning, and Instruction. Lawrence Erlbaum. | 中强。原文提出六项策略——modeling、coaching、scaffolding、articulation、reflection、exploration；**fading 是贯穿其中的设计取向，不是六项之一**。证据以课堂与 apprenticeship 研究为主。 |
| AI 使用需护栏，不提供直接答案 | Bastani, H., Bastani, O., Sungu, A., Ge, H., Kabakcı, Ö., & Mariman, R. (2025). *Generative AI without guardrails can harm learning: Evidence from high school mathematics*. PNAS, 122(26), e2422633122. | 中强。近千名高中生的现场实验：练习期 GPT 接入组成绩提升 48%，但撤走 AI 后该组比从未使用组低 17%；带提示护栏的版本基本抵消该负面影响。样本为单一平台与学科，护栏形态需自行实现。 |
| 探究式学习在大学数学同样成立 | Laursen, S. L., Hassi, M.-L., Kogan, M., & Weston, T. J. (2014). *Benefits for women and men of inquiry-based learning in college mathematics: A multi-institution study*. Journal for Research in Mathematics Education, 45(4), 406–418. | 中强。4 所大学、100 余个课程班。研究对象是大学课堂，家庭一对一场景的对位度需自行评估。 |
| 资料入库前做可检索性体检 | 本项目经验性结论，非文献 | 经验级。同一内容的不同 PDF 版本，文本层可用性可能完全相反。判据见 [`scripts/pdf_readability_probe.py`](scripts/pdf_readability_probe.py)。 |

> 上表为索引而非综述。除末行外均为公开发表研究，请查阅原文判断适用性；本框架不对这些研究的有效性作担保。证据的**反面与边界**见下一节。

## 5. 反向证据：已知的失效条件

只列支持性证据会让上表显得比实际更可靠。以下是同一批研究在什么条件下**不支持**本框架的主张。使用前请先读这一节。

| 机制 | 已知失效条件 | 来源 |
| --- | --- | --- |
| 先尝试后讲解 | 问题解决后接直接教学（PS-I）的优势并非普适。对**程序性知识**，先讲后练（I-PS）效果相当甚至更好；对概念性知识 PS-I 更优。设计保真度高时效应量最大（Hedge's g ≈ 0.58），保真度低时优势消失。 | Sinha, T., & Kapur, M. (2021). *When problem solving followed by instruction works: Evidence for productive failure*. Journal of Research in Science Teaching, 58(6), 1682–1703；Chen, S., & Kalyuga, S. (2020). *Is the learning from generative AI...?* European Journal of Psychology of Education, 35, 607–624. |
| 先尝试后讲解 | 早期综述亦提示：多数支持性研究集中于数学等 STEM 域，**非 STEM 域的两项准实验未发现优势**；研究还集中于少数作者、样本偏窄。 | Loibl, K., Roll, I., & Rummel, N. (2017). *Towards a theory of when and how problem solving followed by instruction supports learning*. Educational Psychology Review, 29, 693–715；Loibl, K., Roll, I., Rummel, N., & Rummel, S. (2020). *When failure fails to be productive*. Instructional Science, 48, 789–807. |
| 先尝试后讲解 | **低龄学生**可能因尚不能意识到"知识缺口"而无法从失败中获益，PF 效应在小学阶段常不成立。 | Mazziotti, C. (2017). *When young students fail to productively learn with Productive Failure* ( doctoral dissertation, Ruhr-Universität Bochum). |
| AI 使用需护栏 | 护栏的有效性取决于护栏本身能否阻止"直接给答案"。该研究显示 GPT Tutor 的缓解效果依赖提示设计；若护栏被绕过，负面影响会重新出现。 | Bastani et al. (2025), 同上。 |

**实践含义**：本框架的"先尝试"环节主要适用于**高中理科的概念性断点**；若断点落在计算流程或程序性技能上，直接讲授可能更快，不应强行走失败—整合路径。

## 6. 如何验证它是否有效

框架本身不产生效果，需要配套判据才能判断是否值得继续投入。建议在启用前写下这几条，启用 4–6 周后逐条核对：

| 判据 | 怎么测 | 通过标准 |
| --- | --- | --- |
| 断点定位是否准确 | 对照学生的实际错题，看被判定为"知识跳跃点"的错题是否确实源于前置知识缺失 | 抽查 5 题，误判 ≤ 1 题 |
| 闸门测试是否有区分力 | 未通过闸门的学生，重新搭桥后是否在闸门题上确有变化 | 至少一次出现可观察的变化，否则该闸门判据无信息量 |
| 闭环是否真的闭环 | 连续统计 5 个工作日的五步完成率 | 完成率 ≥ 80%；未完成日必须有明确转入次日首条的记录 |
| 三查是否发现过问题 | 记录三查实际拦下的错误次数 | 每周 ≥ 1 次，否则该步骤可视为空转 |
| 整体投入产出 | 记录统筹人每周耗时 | 若超过学生有效学习时长的 30%，须重新裁剪流程 |

**判据的元规则**：没有判据的环节一律视为未验证。框架里任何"搭桥完成""状态良好"的描述，如果不能对应到一个可数判据，就不构成闭环。

## 7. 效果边界

- 本框架能从零建立"计划—执行—校验"的流程纪律，**不自动产生提分效果**。
- 效果 ≈ 方法论 × 资料资产 × 每日人力投入 × 环境适配。本 skill 只提供第一项的一部分。
- 学科适配度：理科（数学/物理/化学）验证较充分；文科需调整桥接逻辑，见 [§3](#3-适用与不适用)。
- 红线清单条目多来自具体案例沉淀，使用时须按自身学情裁剪，**不可照搬**。
- 本框架提供的是**流程与判据**，不提供教材内容、题库或数据资产。

## 10. 可检索性体检

**问题**：一份 PDF 能不能被检索，光看文件名、页数、大小都看不出来。实测中同一份内容的两个版本，页数最多、抽取字符数最高的那一版反而是乱码（文本层存在但字符映射缺失，抽出的是无意义字符）；而看起来更小的另一版文本层完全干净。

**做法**：入库或引用前先跑体检，不靠"抽到了字"判定，而靠**常用字命中率**（抽样页中高频汉字占汉字总量的比例）：

```bash
pip install pypdf
python scripts/pdf_readability_probe.py <file.pdf> [<file2.pdf> ...]   # 体检并打印表
python scripts/pdf_readability_probe.py <dir-or-glob> --json out.json   # 落 JSON
python scripts/pdf_readability_probe.py --selftest                      # 自检判据不翻转
```

判定与退出码：正常（可检索）／乱码（需换版本或 OCR）／无文本层（扫描件，需 OCR）／稀疏（公式多为图片，检索价值低）。**存在不可用件时退出码为 2**，可直接串进入库流程当闸门。

## 11. 已知缺口

本框架当前**不提供**以下内容，使用时需自行补齐：

- **导出能力缺失**：交付物为自包含 HTML（可打印、可离线、含内联 SVG 交互），但**没有 Markdown / Anki 等可带走格式的导出通道**。若你的场景需要把内容搬进别的工具，需要另建导出层。
- **交互演示的适用边界**：只有"空间关系 / 动态过程 / 多状态对比"这类卡点才值得做动画；静态图加三句话能讲清的，不做。
- **无配套题库**：框架不产出题目，题目须来自你自己的资料库。
- **未做多学科验证**：理科以外的效果未系统检验。
- **无本框架自身的对照实验**：所有"有效"表述均指单案例观察，不构成群体效应量。

## 12. 脱敏与数据处理

本 skill 为对外发布版本。脱敏范围与方法：

| 项 | 处理 |
| --- | --- |
| 内部代称与代号 | 全部替换为中性表述（"学生甲"等），不出现真实姓名与家庭内部称谓 |
| 内部文件路径与编号 | 不引用，仅以中性描述指代 |
| 实例数据 | 全部为改写后的合成示例，非真实学生记录 |
| 公开来源 | `ORIGIN.md` 保留的公开讨论链接为公开网页，不含工作区信息 |

**数据处理约定**：本 skill 不含任何数据收集与上报逻辑。实际使用时，涉及个人可识别信息的学习材料应留在本地；若交给云端模型处理，按所用产品的数据政策自行评估。

**建议的对外发布自检**（供二次修改者使用）：搜索本目录全部文本，确认不含真实姓名、内部路径、内部编号；确认示例数据与真实记录无法对应。
