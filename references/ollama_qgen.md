# 本机 Ollama 出题链路（只出题，不判读）

## 前提
- 本机已安装 Ollama，并拉取 `qwen2.5:7b`（`7b` / `7b-instruct` 可共用同一 blob，节省磁盘）
- 用于给考生出题；判读 / 批改走云端

## 调用示例
```
ollama run qwen2.5:7b "你是高中[科目]老师。基于以下知识点出 5 道循序渐进的题：[知识点]。要求：梯度由易到难，附答案与解析要点。"
```

## 批量出题（脚本化思路）
- 将当天知识点整理为列表，循环调用，输出 Markdown 题卡；
- 人工挑选后并入打印清单，不直接投喂给学生。

## 红线
- 本地模型仅生成题目，不负责判分 / 批改
- 若需判读，把学生作答送云端模型，不在本机 Ollama 跑判读
