# 每日五步闭环 + 周任务单（模板）

## 每日五步闭环
1. 生成打印清单（按当天各科卷子 / 练习题列明细）
2. 手写执行（学生线下完成）
3. 90 秒三查勾选（查完成度 / 查规范 / 查疑点）
4. 难篇 / 续写拍照送批（疑难页送云端判读）
5. 对答案报结果（数学等科目对答案并汇报）

## 周任务单模板
| 日期 | 科目 | 任务明细 | 闭环状态 | 备注 |
|------|------|----------|----------|------|
| D1 | 数学 | [桥梁阶梯 / 回炉卷] | ☐ | |
| D2 | 物理 | [桥接执行表] | ☐ | |
| D3 | 英语 | [续写 1 篇 + 三查] | ☐ | 词数基线见红线 |

> `D1/D2/D3` 为周内日序占位，按自身节奏替换。

## 交接单（跨日 / 跨线）
- 当日未闭环项 → 次日首条
- 新发现的卡点 → 记入桥梁资产 / 概念攻坚附件
